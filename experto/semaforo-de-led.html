Semáforo de LED

C2Dificultad ★★☆Primaria 10-12 40 minsalidas digitalessecuencia
Objetivo

Montar un semáforo con tres LED (rojo, amarillo y verde) conectados a P0, P1 y P2, y programar su secuencia.

Necesitas

  • Cables de cocodrilo (mejor de colores distintos) (6)
  • Tres LED: rojo, amarillo y verde
  • Tres resistencias de 220 Ω

Conexiones

Paso a paso

Trabajo con:
  1. Cada LED tiene una pata larga (+) y una corta (−). Conecta la pata larga de cada LED a su pin a través de una resistencia de 220 Ω.
  2. Une todas las patas cortas a GND.
  3. En para siemprepor siemprewhile True:, programa la secuencia con escritura digital pin P0 a 1pon pin digital 0 apin0.write_digital(1) y pausa (ms)espera … milisegundossleep(ms): verde 4 s, amarillo 1 s, rojo 4 s.
  4. En cada fase enciende solo el LED que corresponde (1) y apaga los demás (0).
Ayuda: pistas
  • En MakeCode: escritura digital pin P0 a 1 (Pines). En MicroBlocks: pon pin digital 0 a (Pines), con el interruptor verde para encender.
  • Si un LED no se enciende, dale la vuelta: puede estar al revés.
Una solución posible

Elige el editor con el que trabajas: la web lo recordará en las demás prácticas.

Probar en el simulador

Es el simulador oficial de MakeCode: pulsa sus botones, toca el logotipo o mueve los controles de los sensores.

Ver y copiar el código JavaScript
basic.forever(function () {
    pins.digitalWritePin(DigitalPin.P2, 1)
    pins.digitalWritePin(DigitalPin.P1, 0)
    pins.digitalWritePin(DigitalPin.P0, 0)
    basic.pause(4000)
    pins.digitalWritePin(DigitalPin.P2, 0)
    pins.digitalWritePin(DigitalPin.P1, 1)
    basic.pause(1000)
    pins.digitalWritePin(DigitalPin.P1, 0)
    pins.digitalWritePin(DigitalPin.P0, 1)
    basic.pause(4000)
})

En MakeCode abre la pestaña JavaScript, borra lo que haya, pega el código y vuelve a Bloques.

Abrir en MicroBlocks Descargar .ubp

Abre MicroBlocks en Chrome o Edge. Si pregunta si quieres actualizar una biblioteca a una versión nueva, pulsa Sí.

from microbit import *

while True:
    pin2.write_digital(1)
    pin1.write_digital(0)
    pin0.write_digital(0)
    sleep(4000)
    pin2.write_digital(0)
    pin1.write_digital(1)
    sleep(1000)
    pin1.write_digital(0)
    pin0.write_digital(1)
    sleep(4000)

Abrir el editor de Python Descargar .py

En el editor de Python pulsa Abrir… y elige el archivo .py, o pega el código.

¿Y si…?

  • Añade un pulsador de peatones: al pulsar A, el semáforo pasa a rojo antes.
  • Muestra en la pantalla un muñeco andando cuando el semáforo esté en rojo para los coches.
