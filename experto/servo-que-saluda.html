Servo que saluda

S3Dificultad ★★★ESO 40 minservomotorsalidas analógicas
Objetivo

Mover un pequeño servomotor (SG90) con los botones: A lo lleva a un lado, B al otro y el logotipo lo hace saludar.

Necesitas

  • Cables de cocodrilo (mejor de colores distintos) (3) o cables macho para el conector del servo
  • Un microservo SG90

Conexiones

Paso a paso

Trabajo con:
  1. Conecta el servo: cable marrón (o negro) a GND, rojo a 3V y naranja (señal) a P0.
  2. En al presionarse el botón Acuando se pulse el botón Abutton_a.was_pressed() (A), escribir servo pin P0 a 90pon el servo 0 a … gradospin0.write_analog(…) a 0°; en B, a 180°.
  3. En al pulsar el logotipocuando · logo touchedpin_logo.is_touched(), con repetir 4 vecesrepite 10 vecesfor i in range(4): 3 veces, alterna el escribir servo pin P0 a 90pon el servo 0 a … gradospin0.write_analog(…) entre 45° y 135°.
  4. Pega un brazo de cartulina al servo para que se vea mejor el movimiento.

Alimentación

Un microservo SG90 suele funcionar con los 3 V de la micro:bit si se alimenta con pilas nuevas o USB, pero si se reinicia la placa o tiembla, usa una placa de expansión con alimentación propia. No conectes servos grandes directamente.

Ayuda: pistas
  • Un servo no gira sin parar: va al ángulo que le pidas y se queda ahí.
  • MicroBlocks usa ángulos de −90 a 90 (0 es el centro).
  • Python no tiene un bloque de servo: generamos la señal con write_analog (impulsos de 0,5 a 2,5 ms cada 20 ms).
Una solución posible

Elige el editor con el que trabajas: la web lo recordará en las demás prácticas.

Probar en el simulador

Es el simulador oficial de MakeCode: pulsa sus botones, toca el logotipo o mueve los controles de los sensores.

Ver y copiar el código JavaScript
input.onButtonPressed(Button.A, function () {
    pins.servoWritePin(AnalogPin.P0, 0)
})
input.onButtonPressed(Button.B, function () {
    pins.servoWritePin(AnalogPin.P0, 180)
})
input.onLogoEvent(TouchButtonEvent.Pressed, function () {
    for (let index = 0; index < 3; index++) {
        pins.servoWritePin(AnalogPin.P0, 45)
        basic.pause(300)
        pins.servoWritePin(AnalogPin.P0, 135)
        basic.pause(300)
    }
})

En MakeCode abre la pestaña JavaScript, borra lo que haya, pega el código y vuelve a Bloques.

Abrir MakeCode

Usa las bibliotecas Servomotores, TouchPin. Al abrir el proyecto se cargan solas.

Abrir en MicroBlocks Descargar .ubp

Abre MicroBlocks en Chrome o Edge. Si pregunta si quieres actualizar una biblioteca a una versión nueva, pulsa Sí.

from microbit import *

pin0.set_analog_period(20)

def angulo(grados):
    # de 0-180 grados a impulsos de 0,5-2,5 ms (valores de 26 a 128)
    pin0.write_analog(26 + grados * 102 // 180)

while True:
    if button_a.was_pressed():
        angulo(0)
    if button_b.was_pressed():
        angulo(180)
    if pin_logo.is_touched():
        for i in range(3):
            angulo(45)
            sleep(300)
            angulo(135)
            sleep(300)

Abrir el editor de Python Descargar .py

En el editor de Python pulsa Abrir… y elige el archivo .py, o pega el código.
