Casa segura

1-2 sesiones

Una alarma para una casa de cartón: vigila la puerta con un interruptor de aluminio y la luz de una habitación. Se desactiva con una clave secreta de botones.

  1. 1Interruptor de la puertaDos láminas de aluminio (P1 y GND) que se tocan con la puerta cerrada.
  2. 2micro:bitSi se abre la puerta, suena la alarma. La clave A, A, B la desactiva.
  3. 3Casa de cartónUna caja de zapatos sirve: recorta la puerta y las ventanas.

Necesitas

  • micro:bit V2
  • Papel de aluminio y cables de cocodrilo (interruptor de puerta en P1 y GND)
  • Casa de cartón

Paso a paso

Trabajo con:
  1. Monta el interruptor de la puerta como en la práctica C4.
  2. Si la alarma está activa y la puerta se abre o se enciende la luz dentro de la casa a oscuras, suena la sirena.
  3. Para desactivarla hay que pulsar la clave: A, A, B.
  4. El logotipo vuelve a activarla.

Programa

Probar en el simulador

Es el simulador oficial de MakeCode: pulsa sus botones, toca el logotipo o mueve los controles de los sensores.

Ver y copiar el código JavaScript
let activa = true
let clave = ""
pins.setPull(DigitalPin.P1, PinPullMode.PullUp)
input.onButtonPressed(Button.A, function () {
    clave = clave + "A"
})
input.onButtonPressed(Button.B, function () {
    clave = clave + "B"
    if (clave == "AAB") {
        activa = false
        basic.showIcon(IconNames.No)
    }
    clave = ""
})
input.onLogoEvent(TouchButtonEvent.Pressed, function () {
    activa = true
    basic.showIcon(IconNames.Yes)
})
basic.forever(function () {
    if (activa && pins.digitalReadPin(DigitalPin.P1) == 1) {
        basic.showIcon(IconNames.Skull)
        music.play(music.tonePlayable(988, music.beat(BeatFraction.Quarter)), music.PlaybackMode.UntilDone)
        music.play(music.tonePlayable(784, music.beat(BeatFraction.Quarter)), music.PlaybackMode.UntilDone)
    }
})

En MakeCode abre la pestaña JavaScript, borra lo que haya, pega el código y vuelve a Bloques.

Abrir MakeCode

Usa las bibliotecas Pantalla LED, Tonos, TouchPin. Al abrir el proyecto se cargan solas.

Abrir en MicroBlocks Descargar .ubp

Abre MicroBlocks en Chrome o Edge. Si pregunta si quieres actualizar una biblioteca a una versión nueva, pulsa Sí.

from microbit import *
import music

pin1.set_pull(pin1.PULL_UP)
activa = True
clave = ""
while True:
    if button_a.was_pressed():
        clave += "A"
    if button_b.was_pressed():
        clave += "B"
        if clave == "AAB":
            activa = False
            display.show(Image.NO)
        clave = ""
    if pin_logo.is_touched():
        activa = True
        display.show(Image.YES)
    if activa and pin1.read_digital() == 1:
        display.show(Image.SKULL)
        music.pitch(988, 250)
        music.pitch(784, 250)

¿Y si…?

  • Avisa por radio a una placa «móvil» del dueño.

Para el profesorado

Introduce la idea de contraseña y de seguridad: ¿cuántas claves de tres pulsaciones hay? (2 × 2 × 2 = 8). ¿Y de cinco? Es fácil adivinar una clave corta.

  • 10 min: presentación del reto y del material.
  • 15 min: diseño en papel (qué mide, qué decide, qué hace).
  • 25 min: montaje y programación por fases.
  • 10 min: prueba, mejora y presentación al grupo.
