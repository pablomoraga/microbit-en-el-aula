Votación por radio

1 sesión

Toda la clase vota con su micro:bit: A es «sí» y B es «no». La placa del profesorado cuenta los votos y muestra el resultado al tocar el logotipo.

  1. 1VotantesCada placa vota: A = sí y B = no.
  2. 2UrnaCuenta los votos recibidos por radio (grupo 20) y los muestra al tocar el logotipo.

Necesitas

  • Una micro:bit por alumno o pareja (votantes) y una para el profesorado (urna)

Paso a paso

Trabajo con:
  1. Programa de los votantes: A envía 1 y muestra el sí; B envía 0 y muestra el no.
  2. Programa de la urna: al recibir 1 suma a si; al recibir 0, a no.
  3. Al tocar el logotipo de la urna, muestra los dos totales. Con A+B, pone los contadores a cero.

Un mismo programa para todas

Todas las placas llevan el mismo programa: cualquiera puede votar y cualquiera puede contar. Para usarlo como urna basta con tocar su logotipo.

Programa

Probar en el simulador

Es el simulador oficial de MakeCode: pulsa sus botones, toca el logotipo o mueve los controles de los sensores.

Ver y copiar el código JavaScript
radio.setGroup(20)
let si = 0
let no = 0
input.onButtonPressed(Button.A, function () {
    radio.sendNumber(1)
    basic.showIcon(IconNames.Yes)
})
input.onButtonPressed(Button.B, function () {
    radio.sendNumber(0)
    basic.showIcon(IconNames.No)
})
radio.onReceivedNumber(function (receivedNumber) {
    if (receivedNumber == 1) {
        si += 1
    } else {
        no += 1
    }
})
input.onLogoEvent(TouchButtonEvent.Pressed, function () {
    basic.showString("SI")
    basic.showNumber(si)
    basic.showString("NO")
    basic.showNumber(no)
})
input.onButtonPressed(Button.AB, function () {
    si = 0
    no = 0
})

En MakeCode abre la pestaña JavaScript, borra lo que haya, pega el código y vuelve a Bloques.

Abrir MakeCode

Usa las bibliotecas Radio, Pantalla LED, TouchPin. Al abrir el proyecto se cargan solas.

Abrir en MicroBlocks Descargar .ubp

Abre MicroBlocks en Chrome o Edge. Si pregunta si quieres actualizar una biblioteca a una versión nueva, pulsa Sí.

from microbit import *
import radio

radio.on()
radio.config(group=20)
si = no = 0
while True:
    if button_a.is_pressed() and button_b.is_pressed():
        si = no = 0
    elif button_a.was_pressed():
        radio.send("1")
        display.show(Image.YES)
    elif button_b.was_pressed():
        radio.send("0")
        display.show(Image.NO)
    voto = radio.receive()
    if voto == "1":
        si += 1
    elif voto == "0":
        no += 1
    if pin_logo.is_touched():
        display.scroll("SI " + str(si) + " NO " + str(no))

Abrir el editor de Python Descargar .py

En el editor de Python pulsa Abrir… y elige el archivo .py, o pega el código.

¿Y si…?

  • Evita que alguien vote dos veces (cada placa solo puede enviar un voto hasta el reinicio).
  • Haz una encuesta con tres opciones (A, B y logotipo).

Para el profesorado

Sirve para hablar de democracia, privacidad del voto y fiabilidad: ¿qué pasa si alguien pulsa muchas veces? ¿Cómo lo resolverían las elecciones reales?

  • 10 min: presentación del reto y del material.
  • 15 min: diseño en papel (qué mide, qué decide, qué hace).
  • 25 min: montaje y programación por fases.
  • 10 min: prueba, mejora y presentación al grupo.
