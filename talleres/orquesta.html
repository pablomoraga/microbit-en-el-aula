Orquesta micro:bit

1 sesión

Una placa hace de directora y marca el compás por radio; cada placa músico toca su nota en cada compás. Juntas forman acordes y melodías.

  1. 1DirectoraMarca el compás por radio (grupo 30). Con A empieza y para.
  2. 2MúsicosCada placa elige su nota con B y suena en los tiempos 1 y 3.

Necesitas

  • Varias micro:bits V2 (una directora y varias músicas)

Paso a paso

Trabajo con:
  1. La directora: al pulsar A empieza a enviar un número cada medio segundo (1, 2, 3, 4, 1, 2…).
  2. Cada música elige su nota con B (Do, Mi o Sol) y la muestra.
  3. Al recibir un 1 o un 3, la música toca su nota. Así sonarán todas a la vez, como un acorde.

Programa

Probar en el simulador

Es el simulador oficial de MakeCode: pulsa sus botones, toca el logotipo o mueve los controles de los sensores.

Ver y copiar el código JavaScript
radio.setGroup(30)
let notas = [262, 330, 392]
let mia = 0
let tocando = false
let tiempo = 1
input.onButtonPressed(Button.A, function () {
    tocando = !(tocando)
})
input.onButtonPressed(Button.B, function () {
    mia = (mia + 1) % 3
    basic.showNumber(mia + 1)
})
basic.forever(function () {
    if (tocando) {
        radio.sendNumber(tiempo)
        basic.showNumber(tiempo)
        tiempo = tiempo % 4 + 1
        basic.pause(500)
    }
})
radio.onReceivedNumber(function (receivedNumber) {
    if (receivedNumber == 1 || receivedNumber == 3) {
        music.play(music.tonePlayable(notas[mia], music.beat(BeatFraction.Quarter)), music.PlaybackMode.InBackground)
    }
})

En MakeCode abre la pestaña JavaScript, borra lo que haya, pega el código y vuelve a Bloques.

Abrir MakeCode

Usa las bibliotecas Radio, Pantalla LED, Tonos. Al abrir el proyecto se cargan solas.

Abrir en MicroBlocks Descargar .ubp

Abre MicroBlocks en Chrome o Edge. Si pregunta si quieres actualizar una biblioteca a una versión nueva, pulsa Sí.

from microbit import *
import radio
import music

radio.on()
radio.config(group=30)
notas = [262, 330, 392]
mia = 0
tocando = False
tiempo = 1
ultimo = 0
while True:
    if button_a.was_pressed():
        tocando = not tocando
    if button_b.was_pressed():
        mia = (mia + 1) % 3
        display.show(mia + 1)
    if tocando and running_time() - ultimo > 500:
        ultimo = running_time()
        radio.send(str(tiempo))
        display.show(tiempo)
        tiempo = tiempo % 4 + 1
    golpe = radio.receive()
    if golpe in ("1", "3"):
        music.pitch(notas[mia], 250, wait=False)

Abrir el editor de Python Descargar .py

En el editor de Python pulsa Abrir… y elige el archivo .py, o pega el código.

¿Y si…?

  • Que la directora envíe también la nota que debe tocar cada grupo y así interpretar una canción.
  • Cambia el tempo con la inclinación de la placa directora.

Para el profesorado

Una placa directora no recibe sus propios mensajes, así que no suena: es perfecta para el profesorado. Funciona bien con grupos de 3 a 12 placas.

  • 10 min: presentación del reto y del material.
  • 15 min: diseño en papel (qué mide, qué decide, qué hace).
  • 25 min: montaje y programación por fases.
  • 10 min: prueba, mejora y presentación al grupo.
