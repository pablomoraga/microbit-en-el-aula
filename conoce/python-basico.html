Manual básico de Python

Una guía de consulta rápida de MicroPython para la micro:bit V2. Cada apartado explica una idea y la acompaña de un ejemplo corto: cópialo en el editor de Python, pruébalo en el simulador y después cámbialo.

1. Cómo es un programa

# Esto es un comentario: Python no lo ejecuta
from microbit import *

display.scroll("Hola")      # se ejecuta una vez, al empezar

while True:                 # repite para siempre
    display.show(Image.HEART)
    sleep(500)
    display.clear()
    sleep(500)
  • from microbit import * carga las instrucciones de la placa. Va siempre en la primera línea.
  • Las instrucciones se ejecutan de arriba abajo, una detrás de otra.
  • while True: es el bucle para siempre. Lo que va dentro lleva cuatro espacios delante (sangría).
  • sleep(500) espera 500 milisegundos (medio segundo).
  • Con # escribes comentarios: notas para personas que el programa no lee.

2. La pantalla

Texto, números e iconos

scroll desplaza un texto o un número; show muestra una imagen (o un carácter) y se queda fijo.

from microbit import *

display.scroll("Hola clase")
display.scroll(42)
display.show(Image.HAPPY)
sleep(1000)
display.show("A")
  • Algunas imágenes: Image.HEART, Image.HAPPY, Image.SAD, Image.YES, Image.NO, Image.ARROW_N, Image.SKULL, Image.MUSIC_QUAVER. La lista completa está en la pestaña API del editor.

LED a LED

La pantalla tiene coordenadas: x es la columna (0 a 4, de izquierda a derecha) e y la fila (0 a 4, de arriba abajo). El brillo va de 0 (apagado) a 9 (máximo).

from microbit import *

display.clear()
display.set_pixel(0, 0, 9)   # esquina de arriba a la izquierda
display.set_pixel(4, 4, 3)   # esquina de abajo a la derecha, flojito
display.set_pixel(2, 2, 9)   # el centro

Tu propia imagen

Una imagen son cinco filas de cinco números (brillo de 0 a 9) separadas por dos puntos.

from microbit import *

barco = Image("00900:"
              "00990:"
              "00900:"
              "99999:"
              "09990")
display.show(barco)

3. Variables y operaciones

Una variable es una caja con nombre donde guardas un valor. El signo = significa «guarda», no «es igual».

from microbit import *

puntos = 0
puntos = puntos + 1      # ahora vale 1
puntos += 5              # forma corta: ahora vale 6
nombre = "Lucía"
display.scroll(nombre + " tiene " + str(puntos))
OperaciónPythonEjemplo
Sumar, restar, multiplicar+ - *3 * 4 → 12
Dividir/7 / 2 → 3.5
División entera//7 // 2 → 3
Resto%7 % 2 → 1 (sirve para saber si es par)
Potencia**2 ** 3 → 8
Número a textostr()"Tengo " + str(10)
Texto a númeroint()int("25") → 25

Los nombres de variable no llevan espacios ni tildes y no pueden empezar por un número: vidas, nivel_1, temperatura_max.

4. Decisiones

if ejecuta unas instrucciones solo si se cumple una condición; elif («si no, si…») añade más casos y else recoge el resto.

from microbit import *

while True:
    t = temperature()
    if t > 28:
        display.show(Image.SURPRISED)
    elif t < 18:
        display.show(Image.ASLEEP)
    else:
        display.show(Image.HAPPY)
    sleep(1000)

5. Bucles

Repetir un número de veces

for i in range(5): repite cinco veces; la variable i vale 0, 1, 2, 3 y 4.

from microbit import *

for i in range(5):
    display.set_pixel(i, 2, 9)   # enciende la fila del centro, LED a LED
    sleep(200)

Repetir mientras se cumpla algo

while repite mientras la condición sea verdadera. break sale del bucle.

from microbit import *

cuenta = 10
while cuenta > 0:
    display.scroll(cuenta)
    cuenta -= 1
display.show(Image.YES)

6. Botones y logotipo

from microbit import *

while True:
    if button_a.was_pressed():
        display.show("A")
    if button_b.is_pressed():
        display.show("B")
    if pin_logo.is_touched():
        display.show(Image.HEART)
    sleep(50)
  • was_pressed() dice si el botón se ha pulsado desde la última vez que preguntaste: cuenta una vez por pulsación.
  • is_pressed() dice si está pulsado ahora: sirve para acciones que duran mientras lo mantienes.
  • button_a.get_presses() devuelve cuántas veces se ha pulsado y pone la cuenta a cero.
  • Para A y B a la vez: if button_a.is_pressed() and button_b.is_pressed():

while True:
    if accelerometer.was_gesture("shake"):
        display.show(Image.SURPRISED)
        sleep(1000)
    display.scroll(display.read_light_level())

8. Sonido

La V2 tiene altavoz. El módulo music toca notas y melodías; audio reproduce los sonidos expresivos.

from microbit import *
import music

music.play(music.BA_DING)          # melodía incluida
music.pitch(440, 500)              # nota de 440 Hz durante 500 ms
music.play(["C4:4", "E4:4", "G4:8"])   # do, mi, sol (nota + octava : duración)
audio.play(Sound.HAPPY)            # sonido expresivo de la V2
  • Otras melodías: music.BIRTHDAY, music.POWER_UP, music.JUMP_UP, music.ENTERTAINER.
  • Otros sonidos: Sound.GIGGLE, Sound.HELLO, Sound.SAD, Sound.TWINKLE, Sound.YAWN.
  • Para silenciar el altavoz de la placa (por ejemplo, si usas auriculares en P0): speaker.off().

9. Números al azar

from microbit import *
import random

while True:
    if accelerometer.was_gesture("shake"):
        display.show(random.randint(1, 6))     # dado: de 1 a 6, ambos incluidos
    if button_a.was_pressed():
        display.show(random.choice([Image.HAPPY, Image.SAD, Image.HEART]))

10. Listas

Una lista guarda varios valores en orden. El primero está en la posición 0.

from microbit import *

colores = ["rojo", "verde", "azul"]
display.scroll(colores[0])        # rojo
colores.append("amarillo")        # añade al final
display.scroll(len(colores))      # 4

medidas = []
for i in range(5):
    medidas.append(temperature())
    sleep(1000)
display.scroll(max(medidas))      # la más alta (min() da la más baja)

11. Funciones

Una función es un trozo de programa con nombre que puedes usar muchas veces. Se crea con def y puede devolver un resultado con return.

from microbit import *

def parpadear(imagen, veces):
    for i in range(veces):
        display.show(imagen)
        sleep(300)
        display.clear()
        sleep(300)

def doble(n):
    return n * 2

parpadear(Image.HEART, 3)
display.scroll(doble(21))

12. Radio

Las micro:bits se envían mensajes de texto por radio. Todas las que quieran hablar entre sí deben estar en el mismo grupo (de 0 a 255).

from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    if button_a.was_pressed():
        radio.send("hola")
    mensaje = radio.receive()      # None si no ha llegado nada
    if mensaje:
        display.scroll(mensaje)
  • Los mensajes son texto: para enviar un número, conviértelo con str(n) y, al recibirlo, vuelve a número con int(mensaje).
  • Una placa no recibe sus propios mensajes.

13. Pines

Para…Python
Encender o apagar algo (LED, zumbador)pin0.write_digital(1) / pin0.write_digital(0)
Leer si hay contacto (pulsador, interruptor)pin1.read_digital() → 0 o 1
Leer un valor que varía (potenciómetro, sensor)pin1.read_analog() → de 0 a 1023
Dar más o menos potencia (brillo de un LED)pin0.write_analog(512) → de 0 a 1023
Tocar un pin con la manopin0.is_touched()
Activar la resistencia interna (interruptores a GND)pin1.set_pull(pin1.PULL_UP)
from microbit import *

while True:
    valor = pin1.read_analog()      # potenciómetro en P1
    pin0.write_analog(valor)        # LED en P0: más o menos brillo
    sleep(20)

Antes de conectar nada

Repasa la página Precauciones y cuidados: cada pin da muy poca corriente y los motores necesitan una placa de expansión.

14. Errores y cómo leerlos

Muchos errores de escritura los marca el propio editor en la línea donde están. Si el fallo aparece al ejecutarse, la pantalla de la placa (o del simulador) desplaza un mensaje con el número de línea y el tipo de error.

MensajeQué suele significar
SyntaxErrorAlgo está mal escrito: faltan los dos puntos :, un paréntesis o unas comillas.
IndentationErrorLa sangría está descolocada: revisa los espacios al principio de la línea.
NameErrorUsas un nombre que no existe: una variable sin crear, una errata (Display en vez de display) o un módulo sin importar.
TypeErrorMezclas tipos que no encajan, como sumar texto y número sin str().
ValueErrorEl valor no sirve, como int("hola") o un brillo de 12.

Truco para depurar

Muestra en la pantalla el valor de una variable en el punto que falla (display.scroll(x)) o usa print(x) y mira la consola serie del editor, debajo del simulador. Así ves qué está pasando de verdad.

15. Tres programas completos

Dado con sonido

Agita la placa: suena, muestra un número del 1 al 6 y cuenta cuántas tiradas llevas.

from microbit import *
import random
import music

tiradas = 0
while True:
    if accelerometer.was_gesture("shake"):
        tiradas += 1
        music.pitch(880, 80)
        display.show(random.randint(1, 6))
    if button_a.was_pressed():
        display.scroll("Tiradas: " + str(tiradas))

Vigilante del frío

Muestra la temperatura al pulsar A y avisa con una alarma si baja de 15 °C.

from microbit import *
import music

LIMITE = 15
while True:
    t = temperature()
    if button_a.was_pressed():
        display.scroll(str(t) + " C")
    if t < LIMITE:
        display.show(Image.NO)
        music.pitch(1000, 200)
    else:
        display.show(Image.YES)
    sleep(500)

Barra de sonido

Una barra que sube con el ruido de la clase, usando una función y un bucle.

from microbit import *

def barra(filas):
    display.clear()
    for y in range(filas):
        for x in range(5):
            display.set_pixel(x, 4 - y, 9)

while True:
    nivel = microphone.sound_level()     # de 0 a 255
    barra(nivel * 6 // 256)              # de 0 a 5 filas
    sleep(100)
