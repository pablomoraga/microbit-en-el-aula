Podómetro

17Dificultad ★★☆ 25 minvariablesacelerómetro
Objetivo

Contar los pasos que das: cada sacudida suma un paso y el botón A muestra el total.

Paso a paso

Trabajo con:
  1. Crea la variable pasos con Crear una variable…Crea una variablenombre = 0 y, en al iniciaral empezararriba, fuera de while True, fijar … aasigna a … el valorx = 0 pasos a 0.
  2. En si agitarcuando · aceleración > 200accelerometer.was_gesture("shake"), cambiar … por 1aumenta … en 1x += 1 pasos por 1 y enciende un instante el LED central con graficar x yenciende x ydisplay.set_pixel(x, y, 9) y ocultar x yapaga x ydisplay.set_pixel(x, y, 0).
  3. En al presionarse el botón Acuando se pulse el botón Abutton_a.was_pressed() (A), mostrar númeroanima el textodisplay.scroll(n) con pasos.
  4. Sujeta la placa al tobillo o a un bolsillo con una goma y da 20 pasos. ¿Cuenta bien?
Ayuda: pistas
  • En MicroBlocks, espera a que la aceleración pase de 150 y luego a que baje de 120: así cada paso cuenta una sola vez.
  • Si cuenta de más o de menos, cambia los umbrales: esto se llama calibrar.
Una solución posible

Elige el editor con el que trabajas: la web lo recordará en las demás prácticas.

Probar en el simulador

Es el simulador oficial de MakeCode: pulsa sus botones, toca el logotipo o mueve los controles de los sensores.

Ver y copiar el código JavaScript
let pasos = 0
input.onGesture(Gesture.Shake, function () {
    pasos += 1
    led.plot(2, 2)
    basic.pause(100)
    led.unplot(2, 2)
})
input.onButtonPressed(Button.A, function () {
    basic.showNumber(pasos)
})

En MakeCode abre la pestaña JavaScript, borra lo que haya, pega el código y vuelve a Bloques.

Abrir MakeCode

Usa las bibliotecas Sensores básicos, Pantalla LED. Al abrir el proyecto se cargan solas.

Abrir en MicroBlocks Descargar .ubp

Abre MicroBlocks en Chrome o Edge. Si pregunta si quieres actualizar una biblioteca a una versión nueva, pulsa Sí.

from microbit import *

pasos = 0
while True:
    if accelerometer.was_gesture("shake"):
        pasos += 1
        display.set_pixel(2, 2, 9)
        sleep(100)
        display.set_pixel(2, 2, 0)
    if button_a.was_pressed():
        display.scroll(pasos)

Abrir el editor de Python Descargar .py

En el editor de Python pulsa Abrir… y elige el archivo .py, o pega el código.
